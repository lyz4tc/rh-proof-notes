# Contributing / 贡献说明

[English](#english) · [中文](#中文) · [Status / 进度](STATUS.md)

## English

Open a GitHub issue to report an error, ask about a gap, or say which lemma you plan to write up. Identify the Lean declaration and the exact claim. An issue is also a useful place to link an existing exposition.

Use a pull request to add or revise a proof note. Submit in either English or Chinese. If you change the mathematics of a note that has a version in the other language, flag the corresponding passage for follow-up.

- State the objects, quantifiers and hypotheses. Give the steps needed to reproduce the conclusion. For a substantial input you leave to another note, state its role and link to its statement.
- Link the Lean declaration at the revision in [SOURCES.md](SOURCES.md). Credit other expositions at the point of use. Record the license and changes for reused prose. Link to material whose reuse terms are unclear.
- Add new Chinese notes to the [Chinese proof catalogue](PROOFS.zh-CN.md). Update [STATUS.md](STATUS.md) when a reading route, open input, or review changes. To record human review, name the reviewer and specify what they checked. Mention AI assistance where it affected drafting or source reading.
- Submit prose you can license under CC BY 4.0, with any third-party exceptions identified. Reuse only the project materials needed to make the public change understandable.

## 中文

发现错误、想追一个缺口或准备写某条引理时，可以开一个 GitHub Issue。请写明 Lean 声明名、所涉命题，以及希望核对的步骤。找到相关公开解读也可以在这里附链接。

通过 PR 增补或修订证明笔记，中文或英文任选其一。如果修改的证明已有另一语版本，请标出需要同步的段落。

- 写清对象、量词和假设，展开读者需要复述的步骤。核心输入若在别篇证明，写清它在此处的作用，并链接到完整陈述。
- 按[来源页](SOURCES.md)的固定版本链接 Lean 声明。在借鉴处署名。复用正文时登记来源、许可和改动。授权未明确的材料用链接引用。
- 将新增中文稿加入[中文证明目录](PROOFS.zh-CN.md)。阅读路线、待接的输入或复核状态有变化时，更新[进度页](STATUS.md)。记录人工复核时，写明复核人及所核对的段落。AI 参与起草或阅读源码的地方按实际情况标注。
- 提交你有权按 CC BY 4.0 公布的正文，并逐项标明第三方材料的例外。
