# Assembling the global coefficient at a type prime

[Proof catalogue](../../PROOFS.en.md) · [Reading and review status](../../STATUS.md)

### Statement

Let $E$ and $K$ be the project’s lattice and coefficient number fields. Fix two decorated lattices with underlying lattices $N\subseteq E^a$ and $N'\subseteq E^b$. Let $T$ be the rational prime of the fixed word, and let $S_T$ be its specified set of places of $E$. The decoration gives maps $f_Q:N_{(Q)}\to\kappa(Q)$ and $f'_Q:N'_{(Q)}\to\kappa(Q)$ for $Q\in S_T$. Assume the target decoration is valid, so $f'_Q$ is additive on $N'_{(Q)}$ and linear for scalars in $\mathcal O_E$ acting on $\kappa(Q)$ by reduction. Let $\phi_T(x)$ be $1$ when $xN_{(Q)}\subseteq N'_{(Q)}$ and $f'_Q\circ x=f_Q$ on $N_{(Q)}$ for all $Q\in S_T$, and $0$ otherwise.

Let $S_{\rm loc}$ be the union of the type and twist places at which the project supplies local coefficient functions. Write $S_{\rm typ}=S_0\cup S_1$ for its type places, where $S_i=\mathrm{Pr.vG}(i)$ for $i=0,1$. For $P\in S_{\rm loc}$ put $q_P=\#\kappa(P)$. The project prime conditions assert that $q_P=g_i$ for $P\in S_i$, with $g_i$ a rational prime, and that $T$, which lies in every $Q\in S_T$, differs from both $g_i$. In particular $S_T\cap S_i=\varnothing$. Put $S=S_T\cup S_{\rm loc}$ and fix an integer $B\ge1$. Define
$$
H_U=\{x:E^a\to E^b\text{ linear}\mid xN_{(P)}\subseteq N'_{(P)}\text{ for all }P\in U\},\qquad
C=T\left(\prod_{P\in S_{\rm loc}}q_P\right)^B.
$$
Let $w$ be any finite place of $K$, with valuation ring $\mathcal O_{K,w}$, and let $\Phi_P:E^{b\times a}\to K$ be given for each $P\in S_{\rm loc}$.

Assume that for each $P\in S_{\rm typ}$ the function $\Phi_P$ is supported on $H_{\{P\}}$, is invariant under addition of $q_PH_{\{P\}}$, and has values in the $\mathbb Z$-algebra generated by the $q_P(q_P-1)$th roots of unity in $K$. These are the conditions `FnModAt`. For $P\in S_{\rm loc}\setminus S_{\rm typ}$ assume $\Phi_P$ has values in $\mathcal O_{K,w}$ and is invariant under addition of $q_P^B H_{\{P\}}$. These are the conditions `AwayAt`.

For each $i\in\{0,1\}$ the full coefficient
$$
\Xi(x)=\phi_T(x)\prod_{P\in S_{\rm loc}}\Phi_P(x)
$$
has values in $\mathcal O_{K,w}$, is supported on $H_{S_i}$, and satisfies $\Xi(x+z)=\Xi(x)$ whenever $z\in g_iH_{S_i}\cap C H_{S\setminus S_i}$. These three conclusions constitute `DatumAt`.

### Proof

For $P\in S_{\rm typ}$, $q_P$ is prime and $q_P(q_P-1)>0$. Each root of unity generating the stated algebra satisfies the monic polynomial $X^{q_P(q_P-1)}-1$. Algebraic integers form a ring, so $\Phi_P(x)$ is an algebraic integer and hence lies in $\mathcal O_{K,w}$. At the other places the integrality is a hypothesis. Since $\phi_T(x)\in\{0,1\}$, multiplication gives $\Xi(x)\in\mathcal O_{K,w}$. If $\Xi(x)\ne0$, each local factor is nonzero. For every $P\in S_i$ the support of $\Phi_P$ gives $x\in H_{\{P\}}$. The intersection of these conditions is $x\in H_{S_i}$.

Suppose now that $z\in g_iH_{S_i}\cap C H_{S\setminus S_i}$. For $Q\in S_T$ we have $Q\notin S_i$, so $z=Cz_0$ with $z_0$ mapping $N_{(Q)}$ into $N'_{(Q)}$. As $T\mid C$, write $z=Tz_Q$ with $z_Q\in H_{\{Q\}}$. The translate by $z$ preserves the word-prime condition in both directions. If $x$ satisfies that condition and $y\in N_{(Q)}$, then $(x+z)y=xy+Tz_Qy$ belongs to $N'_{(Q)}$. Its decoration is $f'_Q(xy)$ because $\overline T=0$ in $\kappa(Q)$. It therefore equals $f_Q(y)$. Starting from $x+z$ and translating by $-z$ gives the reverse implication. Consequently $\phi_T(x+z)=\phi_T(x)$.

For $P\in S_i$, $q_P=g_i$ and $z\in q_P H_{\{P\}}$, so the type period applies. For $P\in S_{\rm loc}\setminus S_i$ we have $z\in C H_{\{P\}}$ and $q_P^B\mid C$. If $P$ is a type place, $B\ge1$ implies $q_P\mid C$ and the type period applies again. At every remaining place the period is $q_P^BH_{\{P\}}$, which contains $C H_{\{P\}}$. Thus all local factors agree at $x$ and $x+z$. Their product with the word-prime indicator agrees as well.

### Application in the column chain

Use local frames to express the maps in matrix coordinates at each place. A frame taking the standard local lattice onto $N_{(P)}$ and a target frame taking the standard local lattice onto $N'_{(P)}$ identify $H_{\{P\}}$ with integral matrices by composing with the source frame and with the inverse target frame. This identification is linear in $x$, so it transfers both support and periods. The type-place coefficient calculation supplies `FnModAt`. The proof of the twist-place integrality estimate uses that $q_P$ and the determinant normalization are units at $w$, so it applies at the selected type prime when those unit hypotheses hold. The product theorem is applied to ordinary adjacent steps, the penultimate step and the top step to prepare the coefficients for the [type-prime theta-jet bound](changing-the-coset-level-isolates-the-auxiliary-prime.md).
