# A saturated crystalline cocycle module reflects the local condition

[Proof catalogue](../../PROOFS.en.md) · [Reading and review status](../../STATUS.md)

Let $O$ be a discrete valuation ring and $C$ any set. A submodule $Z\subseteq O^C$ is saturated if $a h\in Z$ with $a\in O\setminus\{0\}$ and $h\in O^C$ implies $h\in Z$. Given a commutative $O$-algebra $\Lambda$ and a $\Lambda$-module $B$, write $Z(B)\subseteq B^C$ for the module generated by functions $c\mapsto z(c)b$ with $z\in Z,\ b\in B$.

**Proposition.** For an injection $B'\hookrightarrow B$, a function in $(B')^C$ belongs to $Z(B')$ whenever its image belongs to $Z(B)$. In the local Selmer application $C=G_{F_v}\times\{1,\ldots,r\}$ and $Z$ is the lattice of integral crystalline cocycles. If the auxiliary twist is trivial at $v\mid\ell$, this statement also reflects the finite condition on cohomology.

**Proof.** Identify $B'$ with a submodule. Let $u\in(B')^C$ have an expression $\sum_{i=1}^n z_i b_i$ in $B^C$. Work by induction on $n$, the zero-summand case being immediate. If $z_1=0$, discard it. Otherwise choose one nonzero value $z_1(c_0)$ of least valuation. The nonnegative integral valuations have a minimum, so that value divides every $z_1(c)$. Set $h=z_1/z_1(c_0)$; then $h\in Z$ by saturation and $h(c_0)=1$. Since $u(c_0)\in B'$, the function $h\,u(c_0)$ is in $Z(B')$. Subtract it from $u$. In the given expression the new first coefficient function is $z_1-z_1(c_0)h=0$, and every remaining function $z_i-z_i(c_0)h$ lies in $Z$. The difference is still $B'$-valued. The induction gives the claim.

The crystalline cocycle module is saturated, since the crystalline condition on rational cocycles is a linear condition over the fraction field. Its integral coboundaries contain those of the standard lattice vectors, since every rational coboundary is crystalline. After extending coefficients to either $B$ or $B'$, these coboundaries generate all coboundaries of the local action, using that the auxiliary twist is trivial there. Thus if a cocycle class lies in the finite condition for $B$, its representative lies in $Z(B)$: the discrepancy between it and a sum of the generators is a coboundary, already in that module. Apply the first part to the $B'$-valued representative. Each resulting generator is itself a cocycle, by reduction and scalar multiplication of the original cocycle law. For discrete torsion coefficients these generators are continuous because each coefficient vector is killed by some power of the maximal ideal and the integral cocycle is continuous in the adic topology. This proves membership in the finite condition for $B'$.

The same generator formula shows that under a surjection $B\to B''$ every finite local class in the target can be lifted to a finite local class in the source. Lift each of the finitely many coefficient vectors in an expression for it and use the same integral cocycles.
