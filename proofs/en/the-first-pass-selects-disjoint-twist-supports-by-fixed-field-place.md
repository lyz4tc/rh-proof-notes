# The first pass selects disjoint twist supports by fixed-field place

[Proof catalogue](../../PROOFS.en.md) · [Reading and review status](../../STATUS.md)

In the [two-pass construction](two-passes-give-layered-objects-over-the-same-numerical-context.md), distinguish the completed first core $D_0$ from its retained state $D_1$ before core assembly. The two have matching Galois, twist and form data. Their coefficient places are identified, and every place marked for twisting in $D_1$ is marked in $D_0$. The set of marked places is finite and stable under conjugation. Write $L_0$ for the common fixed coefficient field, Galois over $\mathbb Q$. The retained character choice $C_1$ assigns a valid index $i(v)$ to each coefficient place, together with the associated read of its local data, and that choice is invariant under conjugation. The agreement called `Kept` identifies these initial indices with those in the completed choice $C_0$. Each marked place of the first core has a nonzero index place, the condition needed for the exported existence result.

The result constructs a seed for every requested finite exclusion set $A_i$ of host primes at each index $i$. A seed specifies all of the following.

- a readable index $s(v)$ at each coefficient place, constant under conjugation and on each fibre of marked places above a prime of $L_0$;
- the transported theta data, including the full basis and rank tests at each marked index, for every layer and both choices of side;
- a support $Q_i$, exponent length $k_i$, and ray-quotient character $\psi_i$ valued in the prescribed $\ell_i^{k_i}$-th roots of unity, where $\ell_i$ is the residue characteristic of index $i$. At each used marked index every power $\psi_i^a$ with $\gcd(|a|,\ell_i)=1$ passes the exported good-twist conditions with exclusions $A_i$. Supports of different used marked indices are disjoint.

The input for the character choice is `ExportAt` on $D_0$. It gives one family of truncation exponents and finite theta basis lists. At each initially marked index these lists satisfy the full-rank basis criteria, and for every finite further exclusion there is a good twist with that same input basis and with all coprime powers good simultaneously. The notion of a good twist here includes the project-specific cohomological and integral-form tests on that basis. This proof uses the whole quantified assertion. In particular its coprime-power clause cannot be replaced by an unrelated choice of character for each power.

## Transfer and choose the index

Transport the exported lists and theta data along the identifications between $D_0$ and $D_1$. These identifications fix the host field and carry the ray quotients, coefficient rings, chosen bases and relevant maps to the corresponding objects. Thus the same rank conditions and good-character existence hold at each $i(v)$ for which $v$ is marked. This transport also identifies restriction to any smaller exclusion set.

Two coefficient places are in the same class if they lie above the same prime of $L_0$, or above conjugate primes of $L_0$. This is an equivalence relation, since $L_0$ is preserved by conjugation. For each class containing a marked place choose a single representative $v_*$ from the marked places of the class. At a marked $v$ in that class set $s(v)=i(v_*)$; at an unmarked place retain $s(v)=i(v)$. The source's read condition is invariant when the place is changed within its class, so the new index is readable at $v$. On marked places, equality of classes gives the required compatibility. On unmarked places, conjugation invariance holds already for the retained choice. Thus the new indexing is conjugation invariant everywhere.

## Impose disjointness on the same good choices

The set of indices $s(v)$ used at marked places is finite. Each one equals $i(v_*)$ for a marked representative, so its transferred export gives a good character after excluding any finite list. Enumerate the used indices. At each one invoke the export with $A_i$ enlarged by the union of all supports already chosen. Restrict its good-twist assertion to $A_i$. Its support remains disjoint from the previous supports, because the good-twist assertion for exponent $1$ includes avoidance of the entire enlarged list. This inductively gives disjointness for every pair of different used indices, with all primitive-power tests still in force. Values at unused indices do not enter the marked-place tests and can be supplied by any allowed defaults or by further choices from the same existence clause.

The retained state is available because the level-three finiteness step records its lower origin when selecting the final level-three packet: it keeps the old weight-place set and the old character choice. Thus the seed can be produced for the first core after export and then pulled back along coefficient-field enlargement in the second pass.
